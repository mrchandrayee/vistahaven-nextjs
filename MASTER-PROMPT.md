# Master Prompt — VistaHaven Real Estate Website

Build a premium, editorial-style real-estate agency website named **VistaHaven** using the latest stable Next.js App Router, React, TypeScript and modern CSS. Recreate the design language of the supplied screen recording: warm architectural photography, understated sage accents, generous whitespace, dark charcoal typography, a refined serif display face, small uppercase labels, and restrained motion.

## Visual direction
- Premium, modern property brokerage; elegant rather than flashy.
- Palette: warm white, charcoal, pale sage, muted grey, black footer.
- Typography: DM Sans-style sans serif for UI and Playfair Display-style serif for editorial headings.
- Use large edge-to-edge architectural photography with subtle dark overlays.
- Responsive layout with polished mobile navigation.

## Required page sections
1. Sticky header with VistaHaven wordmark, Home/About/Properties/Agents/Blogs navigation, theme toggle and Contact CTA.
2. Full-width hero with architectural image, “FIND YOUR PERFECT HOME TODAY”, supporting copy, Explore Properties CTA, key stats and social-proof panel.
3. About / introduction section with editorial copy, large interior image and experience statistic.
4. Six service cards: Property Sales, Buyer Representation, Rental Management, Investment Consulting, Property Valuation and Tailored Solutions.
5. Property discovery section with search, property-type filter, price filter, property cards, save/favourite control, details CTA and view-all interaction.
6. Brand mission section with large image and Vision, Expert Team and Tailored Solutions points.
7. Agent profiles with portrait photography and roles.
8. Client testimonial cards with star ratings.
9. FAQ accordion covering buying, affordability, renting, lease termination, investment risks, choosing investments, closing costs and timelines.
10. Full-width contact CTA and multi-column footer.
11. Contact consultation modal with name, email and enquiry type, validation and success state.

## Functional requirements
- All navigation anchors work.
- Mobile menu opens and closes.
- Theme toggle changes the page theme.
- Property search, type and budget filters work together.
- Favourite buttons toggle saved state.
- FAQ items expand/collapse.
- Contact modal opens/closes, validates required fields and shows a success confirmation.
- Use accessible labels and semantic elements.
- Keep content data-driven and components maintainable.

## Technical requirements
- Next.js App Router, TypeScript, React.
- `npm run dev`, `npm run build` and `npm start` scripts.
- Responsive CSS; no dependency on a proprietary backend.
- Add metadata for title and description.
- Use `next/image` for remote property photography and configure the image host.
- Do not claim the recording contains original source code; implement a faithful functional recreation from visible frames.
