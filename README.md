A responsive, interactive **real estate website** for VistaHaven — built with Next.js, TypeScript, and Tailwind CSS featuring property listings, search, and premium UI design.

## ✨ Features

- 🌅 Premium real estate landing page
- 🏠 Property showcase & listings
- 🔍 Property search & filter UI
- 🗺️ Interactive map integration
- 📱 Fully responsive layout
- ⚡ Next.js App Router
- 🎭 Smooth animations & transitions

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Components:** Custom component library

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
